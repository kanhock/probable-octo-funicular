# Python по схеме

Обучающее приложение для iPhone: 25 разделов и 111 уроков, от переменных до паттернов проектирования.
В каждом уроке есть пошаговый визуализатор. Он показывает, какая строка выполняется, какие имена
есть в каждом кадре стека, на какие объекты в памяти они ссылаются и что программа выводит.

Стрелки показывают, какое имя ссылается на какой объект. За уроки, тесты и разобранные примеры
начисляется опыт (XP): есть уровни, серия дней подряд, цель дня и награды.

Все шаги записаны с настоящего Python: каждый пример выполняется под трассировщиком (`build/tracer.py`),
а записанные состояния встраиваются в страницу.

## Как открыть на iPhone

1. Откройте `index.html` в Safari (например, через GitHub Pages: Settings → Pages → ветка, папка `/`).
2. Нажмите «Поделиться» → «На экран „Домой“». Приложение откроется во весь экран, как обычное.

Отметки об изученных уроках хранятся в браузере на этом устройстве.

## Как добавить или изменить урок

Уроки описаны в `build/lessons_*.py`. Комментарий `#! текст` в конце строки кода становится
подсказкой, которая показывается, когда выполняется эта строка.

```
python3 build/build.py   # пересобирает index.html и сообщает о проблемах
```
