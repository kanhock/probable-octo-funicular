# Разбор книг

Здесь лежат подробные разборы книг, собранные по единой структуре.

## Разборы

| Книга | Автор | Вход |
|---|---|---|
| Записки из подполья | Ф. М. Достоевский | [Записки_из_подполья/](Записки_из_подполья/README.md) |

## Структура разбора

```
00_О_книге/              карточка книги: автор, год, жанр, контекст
01_Главы/                что происходит в каждой главе и что в ней важно
02_Конспект/             краткое содержание, хронология
03_Ключевые_идеи/        главные идеи, аргументы, механизмы
04_Цитаты/               цитаты с адресами в тексте
05_Персонажи_и_понятия/  карта сущностей, персонажи, словарь понятий
06_Анализ/               темы и мотивы, структура и стиль, противоречия, контекст
07_Мои_мысли/            открытые вопросы, выводы
08_Материалы/            источники, ссылки, связанные книги
```

## Новая книга

Скопируйте папку [`_шаблон/`](_шаблон/) и переименуйте её по названию книги. Порядок работы:

1. Перед чтением заполните `00_О_книге/карточка_книги.md`.
2. Во время чтения заводите заметку на каждую главу по шаблону `01_Главы/_шаблон_главы.md`, цитаты сразу переносите в `04_Цитаты/`.
3. После прочтения заполните конспект, ключевые идеи и анализ.
4. В конце подведите итоги в `07_Мои_мысли/выводы.md`.
