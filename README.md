# Разбор книги

Шаблон структуры для подробного разбора (анализа) книги.

```
00_О_книге/              — карточка книги: автор, год, жанр, контекст
01_Главы/                — заметки по каждой главе (копируйте _шаблон_главы.md)
02_Конспект/             — краткое содержание всей книги
03_Ключевые_идеи/        — главные идеи и аргументы автора
04_Цитаты/               — важные цитаты со страницами
05_Персонажи_и_понятия/  — персонажи и словарь терминов
06_Анализ/               — темы и мотивы, структура и стиль, критика
07_Мои_мысли/            — выводы, применение, открытые вопросы
08_Материалы/            — ссылки, рецензии, изображения
```

## Как пользоваться

1. Заполните `00_О_книге/карточка_книги.md` перед началом чтения.
2. Во время чтения: на каждую главу создавайте файл `01_Главы/глава_NN.md`
   по шаблону, цитаты сразу переносите в `04_Цитаты/`.
3. После прочтения: заполните конспект, ключевые идеи и анализ.
4. В конце — подведите итоги в `07_Мои_мысли/выводы.md`.
