# Python по схеме

Обучающее приложение для iPhone: 25 разделов и 111 уроков, от переменных до паттернов проектирования.
В каждом уроке есть пошаговый визуализатор. Он показывает, какая строка выполняется, какие имена
есть в каждом кадре стека, на какие объекты в памяти они ссылаются и что программа выводит.

Стрелки показывают, какое имя ссылается на какой объект. За уроки, тесты и разобранные примеры
начисляется опыт (XP): есть уровни, серия дней подряд, цель дня и награды.

Все шаги записаны с настоящего Python: каждый пример выполняется под трассировщиком (`build/tracer.py`),
а записанные состояния встраиваются в страницу.

## Как установить на iPhone как приложение

1. Включите GitHub Pages: репозиторий на GitHub → **Settings → Pages** → Source: **Deploy from a branch** →
   выберите ветку с приложением и папку `/ (root)` → **Save**. Через минуту приложение будет доступно по адресу
   `https://kanhock.github.io/probable-octo-funicular/`.
2. Откройте этот адрес в **Safari** на iPhone.
3. Нажмите **«Поделиться» → «На экран „Домой“»**. Появится иконка «Python схема». Приложение открывается
   на весь экран и работает без интернета (service worker держит копию у себя).

## Как устроено обучение

- **Карта из 9 зон** (Деревня основ, Перекрёстки, Мастерская функций, Город классов, Машинное отделение,
  Порт, Река потоков, Глубины памяти, Вершина архитектора). У каждой зоны есть ворота с пояснением
  «что здесь и зачем» и ориентир, показывающий её идею.
- **Урок нельзя закрыть, пока ты не понял**: в примере есть остановки «предскажи значение», а в конце —
  проверка, на которую нужно ответить верно.
- **В каждом уроке** есть блоки «Под капотом» (как это устроено в CPython), «Частые ошибки», «Связано с»
  и проверочные вопросы. Сборка запускает код каждого вопроса «что выведет?» и сверяет ответ с реальным выводом.
- **Интервальное повторение**: вопросы пройденных уроков возвращаются через 1, 3, 7, 16 и 35 дней.

## Профили и данные

- При первом запуске создаётся профиль: имя, цвет героя и PIN из 4 цифр. На одном устройстве может быть
  несколько профилей.
- Профили, прогресс и заметки к урокам хранятся в маленькой базе **IndexedDB** прямо в браузере телефона
  (если она недоступна — в localStorage). На сервер ничего не отправляется.
- PIN хранится в виде хеша SHA-256 с солью. Он защищает от случайного входа, но не заменяет настоящую защиту.
- В профиле есть резервная копия: «Скопировать копию» кладёт данные в буфер обмена, «Восстановить» возвращает их.

## Как добавить или изменить урок

Уроки описаны в `build/lessons_*.py`, углублённые материалы и вопросы — в `build/deep_*.py`, зоны карты — в `build/zones.py`. Комментарий `#! текст` в конце строки кода становится
подсказкой, которая показывается, когда выполняется эта строка.

```
python3 build/build.py   # пересобирает index.html и сообщает о проблемах
```
